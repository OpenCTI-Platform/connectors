# OpenCTI ENISA EUVD Connector

> Scaffolding in progress. This README is a placeholder and will be completed
> in the last implementation step (see the implementation plan discussed with
> the user).

The ENISA EUVD connector imports vulnerability intelligence from the
[European Union Vulnerability Database](https://euvd.enisa.europa.eu/) (EUVD),
published by ENISA (European Union Agency for Cybersecurity).
