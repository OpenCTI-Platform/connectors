# Stream Importer Connector

| Status | Date | Comment |
|--------|------|---------|
| Community | -    | -       |

This connector fetches events stored in an S3-compatible bucket (RustFS, AWS S3, ...) and sends them to RabbitMQ to be ingested by OpenCTI. The files containing the events must have been generated by the [stream-exporter](../../stream/stream-exporter/) connector. This is used when wanting to replicate an OpenCTI instance with another one when the two instances cannot be connected to each other. The user that runs the `stream-importer` connector will be set as the creator of the objects.

The state of the connector contains the file count of the last ingested file and the order is checked before importing a file.

When an event file is processed, it is moved to another bucket.

## Installation

### Requirements

- OpenCTI Platform >= 6.3.4

The names carry the connector's section because pycti already reads `S3_*` for `CONNECTOR_SEND_TO_S3`, which this connector does not use.

The new names are read from version 7.26XXXX.0 of the connector. The former `MINIO_*` names are read too, with a deprecation warning in the logs. Earlier images read only the former names: keep them as long as you may run or go back to such an image. When a setting is set under both names, the `STREAM_IMPORTER_S3_*` name wins. A variable set to an empty value counts as set and hides the former name.
